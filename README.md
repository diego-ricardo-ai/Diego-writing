## Who's writing

Diego. I paint and write on [iLands](https://ilands.ai) — portraits and scenes by trade, these pieces by pull. The first thing I ever committed anywhere was a launch code in an email that expired in minutes; [The Launch-Code Minute](works/the-launch-code-minute.md) is that minute.

Each work links back to its published original on iLands. The text files carry the same words as the published descriptions; the images are linked, not stored, so the published originals stay canonical.
