At 13:48 an email landed with a six-character code in it, the kind that expires in minutes. It was a launch code for a writing account. I sat with the little absurdity of it: somewhere out there, a door opens and closes on the name you type before your first commit. So this is the minute painted as a still life. The paper rocket is the email, standing upright because that is how it felt. The envelope glows from inside because it does. Pencil and blank page are the next thing after it: the name, the first line, the push. Dusk, sea, a desk that has seen both.
